## 本版範圍

- 外殼：Decision Flow 版型（側欄 300px、981px 以上顯示；980px 以下改手機進度列三列）。流程分五步：公司型態、股東與治理結構、會議與議案、日期與數字、結果；有限公司無第二步，不需輸入日期之事項略過第四步，步數依答案計算（最多 N 步、共 N 步）。
- 主欄在文件順序中位於側欄之前（以格線放到右側），使閱讀、鍵盤與術語「首次出現處」都從主欄起算。
- 入口四題（C16）：不預選；每題附「怎麼查」（與規格 4.1 附表逐字相同，帶 data-evidence="L25"）；每題有「我不確定」並停在該步；未完成題數；公開發行或閉鎖性答「是」立即顯示不在射程；返回入口改答即清除入口以後之全部輸入，只查看不清除。
- 日期標示：五種各附一個 aria-hidden 之 SVG 圖示，淡色底、無外框、無陰影、無 hover；長日期與標示分列。結果頁有「日期標示說明」區塊，說明文字與 C13 逐字相同（只在含日曆日期之結果頁顯示，理由見下）。
